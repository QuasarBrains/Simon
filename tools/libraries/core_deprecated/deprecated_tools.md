I feel the need to explain why these are here. Mostly for fun because I wrote these myself back in 2024 when coding agents didn't really have any commercial viability. It was fun to give an LLM tools and see how it would try to go step by step to complete a task. It oftentimes hallucinated inputs, or called the tool syntactically correclty but failed at basic operations like line changes. I would fiddle with it for hours to try to get the agent to edit a file consistently. Anyway, these tools are no longer useful, all tooling is being moved to different modules you see here, but I'm keeping these for the sake of personal history.
